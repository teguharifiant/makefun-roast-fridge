## The roast

> My ice dispenser is a slot machine: pull the lever, watch the lights, and collect your payout in crushed dreams.

One line, 112 characters. The ice dispenser is a casino game bolted to the
fridge door: same lever, same lights, same ritual — except the payout is
always crushed dreams.

## How it works

`main.ts` writes the roast, exactly as above, to `/output/entry.txt` and
prints it. Nothing else is read, fetched, or installed; the program is fully
deterministic — run it twice and the file is byte-identical.

```sh
node main.ts
```

Requires Node 22.18 or later (Node runs the TypeScript directly).
